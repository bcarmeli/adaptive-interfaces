# Language as Adaptive Interface

## One-Line Summary

Language can be studied as an adaptive interface for partner selection and cooperative task execution, not only as a channel for information transfer.

## Core Thesis

When communication is used for partner selection under uncertainty, agents use it to expose, infer, and negotiate affordances. Over repeated interactions, the communicative interface may adapt toward forms that better support selection, task execution, or some tradeoff between them.

## Two Phases

- Selection phase: the sender evaluates receivers through exposed interfaces.
- Task execution phase: the selected sender-receiver pair must use the interface to coordinate and solve the task.

## Key Tension

Selection pressure can reward interfaces that make a receiver look useful. Task-success pressure rewards interfaces that make the receiver actually useful after selection.
