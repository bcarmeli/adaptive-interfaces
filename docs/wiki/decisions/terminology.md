# Terminology Decisions

## Current Preferences

- Use **communicative interface** rather than only communication when emphasizing the observable surface used for interaction.
- Use **affordance** when emphasizing what a receiver makes possible for a sender in a task.
- Use **task-relevant affordance** when the affordance is tied to downstream task success.
- Use **latent capability** for what the receiver can do internally or operationally.
- Use **mutual interpretability** for the sender-receiver ability to use the interface together.
- Use **faithful / unfaithful self-presentation** instrumentally, not morally.

## Avoid or Use Carefully

- **Compatibility**: too broad unless explicitly defined.
- **Natural language is suboptimal**: too strong; prefer saying natural language is one possible interface.
- **Deception**: useful but should be framed as reward-shaped behavior, not moral failure.
- **Full observability of latent space**: potentially misleading because interaction still requires public references.
