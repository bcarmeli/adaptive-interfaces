# Project Overview

## One-Line Summary

This project studies communication as an adaptive interface for exposing task-relevant affordances under partner selection and cooperative task execution.

## Core Motivation

Emergent communication work often evaluates communication by downstream task completion under shared objectives. This project adds an earlier role: communication helps agents decide which partners to engage with before task execution begins.

## Central Claim

Language and other communicative systems are not transparent windows into cognition. They are interfaces that expose selected aspects of latent capabilities. Since affordances are relative to the user of the interface, the same receiver may be useful to one sender and not to another.

## Key Structure

- A sender interacts with multiple receivers during a warm-up or courtship-like phase.
- Receivers expose capabilities through a communicative interface.
- The sender selects one receiver.
- The selected pair performs a downstream task.
- Rewards create pressure on receivers to shape the interface used for selection and execution.

## Research Direction

The project aims to design minimal environments where communicative interfaces can adapt under selection pressure, task-success pressure, or both.
