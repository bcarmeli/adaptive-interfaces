# Source Summary - Language as an Adaptive Interface

## One-Line Summary

A working research direction framing language as an adaptive interface for partner selection and cooperative task execution.

## Key Points

- Communication helps determine which partners to engage with.
- Agents expose only partial views of their latent capabilities through communicative interfaces.
- Sender-side selection and downstream task execution both depend on the interface.
- Receivers may shape their interface under selection and task-success pressure.
- Affordances are agent-relative and must be inferred through the interface.

## Open Questions

- What task can demonstrate non-trivial interface adaptation?
- How should task-relevant affordances be measured?
- How can experiments separate selection pressure from task-success pressure?
